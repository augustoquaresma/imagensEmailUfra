# Prática Progressiva – Desenvolvimento Web com HTML5

**Duração:** 40 minutos  
**Tema:** Introdução ao HTML5  
**Objetivo:** desenvolver progressivamente uma página Web utilizando a estrutura básica do HTML5, elementos de texto, listas, links, imagens, tabelas e formulários.

---

## 1. Estrutura básica do HTML5

Crie um arquivo chamado:

`index.html`

Adicione a estrutura básica:

```html
<!DOCTYPE html>
<html lang="pt-BR">

<head>
    <meta charset="UTF-8">

    <meta
        name="viewport"
        content="width=device-width, initial-scale=1.0"
    >

    <title>Meu Perfil</title>
</head>

<body>

    <!-- Conteúdo da página -->

</body>

</html>
```

### Desafio

Altere o conteúdo da tag `<title>` para que o título apresentado na aba do navegador seja:

**Minha primeira página HTML**

---

# 2. Cabeçalho e apresentação

Dentro da tag `<body>`, crie o cabeçalho da página:

```html
<header>

    <h1>Meu Perfil</h1>

    <p>
        Minha primeira página utilizando HTML5.
    </p>

</header>
```

Agora crie o conteúdo principal:

```html
<main>

    <section>

        <h2>Sobre mim</h2>

        <p>
            Olá! Meu nome é João da Silva.
            Sou estudante do curso de
            <strong>Licenciatura em Computação</strong>.
        </p>

        <p>
            Tenho interesse em desenvolvimento de sistemas
            e estou começando meus estudos em
            <em>Desenvolvimento Web</em>.
        </p>

    </section>

</main>
```

### Elementos utilizados

- `<header>` – cabeçalho da página;
- `<main>` – conteúdo principal;
- `<section>` – seção do documento;
- `<h1>` – título principal;
- `<h2>` – título de segundo nível;
- `<p>` – parágrafo;
- `<strong>` – destaque/importância;
- `<em>` – ênfase.

### Desafio

Modifique o conteúdo da seção utilizando suas próprias informações.

---

# 3. Criando listas

Dentro do `<main>`, crie uma nova seção:

```html
<section>

    <h2>Meus interesses</h2>

    <ul>
        <li>Desenvolvimento Web</li>
        <li>Inteligência Artificial</li>
        <li>Desenvolvimento Mobile</li>
        <li>Banco de Dados</li>
    </ul>

</section>
```

Agora crie uma lista ordenada:

```html
<section>

    <h2>Tecnologias que quero aprender</h2>

    <ol>
        <li>HTML</li>
        <li>CSS</li>
        <li>JavaScript</li>
        <li>Vue.js</li>
        <li>Spring Boot</li>
    </ol>

</section>
```

### Elementos utilizados

- `<ul>` – lista não ordenada;
- `<ol>` – lista ordenada;
- `<li>` – item da lista.

### Desafio

Adicione pelo menos **três novos itens** em uma das listas.

---

# 4. Trabalhando com links

Crie uma seção para links:

```html
<section>

    <h2>Links úteis</h2>

    <p>
        <a
            href="https://developer.mozilla.org/"
            target="_blank"
        >
            MDN Web Docs
        </a>
    </p>

    <p>
        <a
            href="https://github.com/"
            target="_blank"
        >
            GitHub
        </a>
    </p>

</section>
```

A tag `<a>` é utilizada para criar links.

O atributo:

```html
target="_blank"
```

faz com que o endereço seja aberto em uma nova aba.

### Desafio

Adicione um terceiro link para um site relacionado à programação.

---

# 5. Trabalhando com imagens

Crie uma nova seção:

```html
<section>

    <h2>Minha imagem</h2>

    <img
        src="imagem.jpg"
        alt="Minha imagem de perfil"
        width="300"
    >

</section>
```

### Principais atributos

- `src` – endereço da imagem;
- `alt` – descrição alternativa;
- `width` – largura da imagem.

A imagem `imagem.jpg` deverá estar na mesma pasta do arquivo `index.html`.

### Desafio

Crie uma pasta chamada:

`img`

Mova a imagem para essa pasta e altere o atributo `src` corretamente.

---

# 6. Criando uma tabela

Crie uma seção chamada **Minha rotina de estudos**:

```html
<section>

    <h2>Minha rotina de estudos</h2>

    <table border="1">

        <thead>

            <tr>
                <th>Dia</th>
                <th>Conteúdo</th>
                <th>Horas</th>
            </tr>

        </thead>

        <tbody>

            <tr>
                <td>Segunda-feira</td>
                <td>HTML</td>
                <td>2 horas</td>
            </tr>

            <tr>
                <td>Quarta-feira</td>
                <td>CSS</td>
                <td>2 horas</td>
            </tr>

            <tr>
                <td>Sexta-feira</td>
                <td>JavaScript</td>
                <td>3 horas</td>
            </tr>

        </tbody>

    </table>

</section>
```

### Elementos utilizados

- `<table>` – tabela;
- `<thead>` – cabeçalho;
- `<tbody>` – corpo;
- `<tr>` – linha;
- `<th>` – célula de cabeçalho;
- `<td>` – célula de dados.

### Desafio

Adicione mais **duas linhas** à tabela.

## Tipos de campos utilizados

Durante a prática foram utilizados diferentes tipos de `<input>`:

| Tipo | Finalidade |
|---|---|
| `text` | Entrada de texto |
| `email` | Endereço de e-mail |
| `password` | Senha |
| `tel` | Telefone |
| `date` | Data |
| `time` | Hora |
| `datetime-local` | Data e hora |
| `number` | Valores numéricos |
| `range` | Intervalo de valores |
| `radio` | Escolha de uma opção |
| `checkbox` | Escolha de múltiplas opções |
| `color` | Seleção de cor |
| `file` | Seleção de arquivo |
| `url` | Endereço Web |
| `search` | Campo de pesquisa |
| `hidden` | Informação oculta |
| `submit` | Envio do formulário |
| `reset` | Limpeza do formulário |

Também foram utilizados:

- `<label>`;
- `<select>`;
- `<option>`;
- `<textarea>`;
- `<button>`.

# 10. Desafio final

Após concluir a página, realize as seguintes modificações:

1. Altere todas as informações pessoais para seus próprios dados.
2. Adicione pelo menos **cinco tecnologias** de seu interesse.
3. Adicione uma imagem.
4. Crie pelo menos **três links externos**.
5. Acrescente duas linhas à tabela.
6. Utilize pelo menos **10 tipos diferentes de `input`** no formulário.
7. Adicione um novo campo ao formulário que não esteja no exemplo.
8. Torne pelo menos três campos obrigatórios utilizando `required`.
9. Utilize `placeholder` em pelo menos três campos.
10. Teste o formulário tentando inserir informações inválidas nos campos `email`, `number` e `url`.

- compreender a estrutura básica de um documento HTML5;
- utilizar elementos semânticos;
- trabalhar com títulos e parágrafos;
- criar listas ordenadas e não ordenadas;
- inserir links e imagens;
- construir tabelas;
- criar formulários;
- utilizar diferentes tipos de campos HTML5;
